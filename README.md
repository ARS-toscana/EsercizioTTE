# EsercizioTTE
Questo repository contiene un esempio di script per la conduzione di una Target Trial Emulation basata su dati amministrativi italiani. Lo scopo di questo codice è didattico, e i dati contenuti nel repositry sono simulati.

Lo script implementa lo studio simulato il cui protocollo si trova a [questo link](https://docs.google.com/document/d/1I-wd7GWlaKxPp6ZlQHGuis6ksHDSb8MfDjzSG0-qWzU/edit?tab=t.0)
